# PokéInfo

A simple application for looking up Pokémon details using PokeAPI.

## Requirements

- Python >= 3.12
- [uv](https://docs.astral.sh/uv/) (or pip)

## Usage

### Command Line Interface (CLI)

Look up one or more Pokémon directly from the terminal:

```bash
uv run python main.py charizard
uv run python main.py pikachu bulbasaur
```

### Streamlit Web UI

Launch the minimal web interface:

```bash
uv run streamlit run app.py
```
